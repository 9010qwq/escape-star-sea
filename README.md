# 逃离星海 · 人机对战试玩

[直接开始游戏](https://9010qwq.github.io/escape-star-sea/)

一位玩家与一位 AI 的桌游对战。掷骰航行、经营资源和装备，把反击留给关键时刻，穿越三层宇宙后逃离星海。

- 无需登录或安装，手机和电脑浏览器打开即可玩。
- 首次推荐体验局：升阶依次消耗 1、1，最终逃离需要 2 点曲速。
- 点击手牌，在牌内选择目标并确认。点击装备槽查看详情、换装或卸装。
- 手机推荐横屏：地图与当前操作并排显示，手牌从底部展开；点选后可直接在牌内操作。地图和手牌各自滑动，不需要来回翻整页。
- 竖屏进入时会提示旋转手机，也可选择继续竖屏兼容模式。支持的浏览器可点击“全屏”。
- 存档保存在当前浏览器，可从菜单导出；换设备或地址不会自动同步。

此试玩版使用本地策略 AI，无外部模型调用和 API 密钥。每位访客有独立的对局，不支持真人联机。

## 离线试玩

在 [Releases](https://github.com/9010qwq/escape-star-sea/releases) 下载试玩包，解压后用电脑浏览器打开 `index.html`。手机建议使用上面的在线地址。

下文保留1.0.5本地验收记录。`02_美术接入与验证.md`是此前1.0.3的历史说明，当前规则与展示范围以本页、游戏内说明和rules.html为准。提交历史保留旧版，未修改多人分支，也未向比赛或招聘方提交。

**启动：**完整解压后，用电脑浏览器打开同目录 `index.html`。无需安装、登录、联网或 API。每位朋友在自己的浏览器里与本地 AI 对战；本包不是旧 1.1.x 多人联机版。可编辑源码就是随包的 HTML、JS、CSS 和 assets，源码目录为项目中心/单人人机朋友试玩版_1.0.5。

## 1.0.5相对1.0.4的定向改动

| 修前 | 修后 |
|---|---|
| 个人回合的行动牌总提示“点击使用”；短距掠夺没有同格对手时，展开才显示笼统的“没有合法目标”。 | 手里的牌直接显示“没有同格对手”，展开后保留同一原因，确认不可用，不再标成可出牌。 |
| 交易资源不足时也只说没有目标。 | 给出“需10动力，你有9；还差1动力”；资源满足后自动恢复“点击使用”。装备造成的折扣、改为掠夺等条件沿用现有规则。 |
| 没选目标或步数时，确认按钮只是灰着。 | 在原按钮旁明确写出还需选择的目标、地图格或步数；选好后提示消失、按钮恢复。响应或对手回合也说明当前等待事项。 |

规则核心、AI、47种144张卡牌、原作美术与整体布局保持不变。仍采用已披露的“后打先结算”“移动牌不抽基础牌、保留终点明确奖励”电子解释，详见 rules.html。1.0.4 完整保留。本版采用独立浏览器保存名，避免覆盖旧局；菜单仍可导入同规则的 1.0.4 存档。

## 原1.0.5本地验证记录

10项定向检查通过：同格/不同格、交易差额与装备修正、保护、对手回合、弃牌、终局、响应种类和只读边界。实际浏览器正常开局后，从菜单导入合法测试局面，检查原因与禁用按钮；390×844视口选3格、确认定向跃迁，实际到达弥漫星云并增加3动力，交易提示由缺1动力变为可使用。截图为真实运行画面；定向存档是测试构造局面，不冒称自然整局或真人试玩。

核心与素材文件逐字节对比1.0.4，复用原版本未受影响证据；没有重跑整局AI压力测试。包内CRC、相对资源与源码一致性单独核对。实体手机、实际触摸、微信、Safari、Tap宿主、真人理解与平衡仍未测。这段是公开更新前的本地验收记录，不代表真人体验验收。

## 请朋友只反馈这三件事

1. 有牌不能用时，你能否仅看牌旁提示说清原因？请指出最不清楚的一张牌。
2. 确认按钮不能点时，你是否知道还要先选什么？请写下卡名和当时看到的提示。
3. 条件满足后，你是否看得出这张牌已经能用了？有没有仍像不能用或提示变化不清楚的情况？

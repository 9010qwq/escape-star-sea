# 逃离星海 · 原作地图人机试玩 1.0.3

[打开本地游戏](index.html) · [查看原作地图与差异](map-source.html) · [完整规则](rules.html) · [接入方式与验证范围](02_美术接入与验证.md)

一位玩家与星海领航员 AI 对战：掷骰航行、经营资源和装备，穿越三层宇宙。这个版本把用户提供的最新纸面地图美术接入了可操作的星图，保留黑色星尘、银色轨道、蓝色颗粒星体和月牙。棋子、格子效果、路线与按钮由游戏实时绘制。

## 开始玩

完整解压后，用电脑浏览器打开 `index.html`，无需安装依赖。首次推荐“体验局”：升阶依次消耗 1、1，最终逃离需要 2 点曲速。

- 星图默认近看，可以滑动。点格子查看完整效果，点详情框外的空白处即可关闭。
- “全图总览”查看当前宇宙布局；“近看格面”恢复可读格面；“定位”返回自己的棋子。
- “专注星图”暂时扩大地图查看区，“返回对局”恢复操作界面。横屏也能使用，不要求把所有内容挤进一屏。
- 点击手牌，在牌内选择目标并确认；点击装备槽查看、换装或卸装。收起手牌后继续查看地图。
- 存档保存在当前浏览器，可从菜单导出。换浏览器、设备或网址不会自动同步。

此版使用本地策略 AI，没有外部模型调用或 API 密钥。每位访客独立进行人机对战，不包含多人房间服务。

## 地图与规则

原图没有被覆盖。游戏加载约 1 MB 的网页副本，并在网页显示层遮去原图中的文字和旧路线，重新绘制可点击格面及当前规则的路线。三个宇宙各自保持固定宽高比，不把星体拉伸成扁条。

本轮没有修改规则核心、卡牌数据、AI 或对局管理。纸面地图与既有电子版仍有两处数值差异，以及第三宇宙两处格子位置差异；详见[原作与差异页面](map-source.html)。当前结算以游戏详情为准，这不代表已经裁定纸面最新版规则。

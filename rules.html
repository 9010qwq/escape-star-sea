三步启航

01 / 观察

掷骰，选择落点

公开两枚骰子，各自选一枚。看计划路线、资源收益和跃迁点，再锁定移动。

02 / 经营

积累动力与曲速

在合适的位置购买曲速、进入下一宇宙。牌与装备能改变收益，也能打断对手。

03 / 逃离

触发宇宙之眼

带足最终曲速，准确停在眼格，或由右下虫洞经眼传送，完成最后一步。

首次体验可选“体验局＋宽松”。点手牌后，直接在牌上选择目标和确认；点地图格查看效果。“近看格面”保留文字，“全图总览”便于看路线，“专注星图”可以暂时扩大地图。

资源与开局

能源
范围 0—10。降至 0 会安排后续跳轮与恢复；能源不足时，强制损失降到 0。
动力
用来交易、购买曲速，也会被掠夺。最低 0；购买与交易必须足额支付。
曲速
跨阶与逃离时支付门槛。可以提前积累，多余曲速会保留到下一宇宙。

双方从第一宇宙的星际驿站出发，初始能源 10，随后取得起点收益；双方可选同一驿站。起手通常为 2 张常规牌，印有额外常规牌的驿站会增加起手张数。

能源耗尽、停滞与公开信息

能源耗尽通常跳过下一完整轮，随后恢复至至少 5 能源。宽松模式不重复增加已有的同长度待跳轮；严格模式会按来源追加。实际待跳轮以资源栏和记录为准。

跳轮不参与该轮移动、落点、摸牌和个人回合，仍可在适用窗口进行瞬发响应。能源恢复不自动取消其他停滞安排。

位置、资源、装备、手牌数量与公共骰公开。你可以查看自己的手牌，AI 只使用自己的手牌和公开局势；对手手牌内容与实际牌堆顺序不公开。

一轮怎么走

  1. 检查状态，公开掷骰。 本轮掷骰玩家掷两枚六面骰；双方各选一枚，可以选同一个点数，同点不重掷。
  2. 锁定路径，同步移动。 看清计划落点后确认。途中可能出现经过装备、购买曲速与跨阶窗口，按操作区提示完成。
  3. 依次结算落点。 从本轮掷骰者开始，先处理适用响应，再处理格子资源、判定、移动、跃迁和胜利检查。
  4. 统一摸牌。 落点处理完后再摸本轮应得的牌，随后处理雷达选择与立即牌。刚摸到的牌不能回头响应已经结束的事件。
  5. 轮流进行个人回合。 可连续打出合法普通牌、装备或卸装，也可以不出。结束时若手牌超过 3 张，需弃至 3 张，再轮到另一方。

普通无特殊落点通常摸 2 张常规牌；印刷“获得 1 张牌”的额外收益另加。未知星域为 1 张机遇牌＋1 张常规牌。脉冲星、暗物质晕等特殊格按各自说明处理。

曲速、跨阶与获胜

模式第一 → 第二第二 → 第三第三宇宙逃离

正常计格移动经过或停在跃迁点、或【自选跃迁】传到跃迁点时，可按窗口购买曲速。通常每点需 — 动力；【专享折上折】将价格降为 — 动力。购买次数不限，一次可以买多个。

前两阶达到门槛会自动支付对应曲速，选择下一阶驿站并结算；该次剩余步数停止。超额购买的曲速继续保留。第三宇宙仍需合法触发宇宙之眼并支付最终门槛，单纯存够曲速不会自动获胜。

有人逃离后，完成当前轮；双方同轮逃离算平局，否则先逃离者获胜。认输会立即结束本局。

三种门槛沿用已确定的电子版模式。本批原作图片没有完整列出三阶段门槛数表，不将这些参数冒称为纸面原文。

移动、传送与“经过”

每沿普通箭头进入下一格，计为 1 步。三个宇宙都不提供普通短、长分岔选择；第三宇宙的普通行进与虫洞、隧道的条件传送是不同路线。

右下虫洞准确落点时，经宇宙之眼结算并检查逃离，再去左上出口；普通经过右下虫洞则继续前往引力波风暴。两处奇异隧道在落点另掷判定骰，按结果传送或取得资源变化。判定骰与公共移动骰分开。

两张移动牌

电子版对“不抽牌”的当前解释牌效移动会结算最终格，但不进行基础摸牌；终点印刷的额外牌、未知格专门摸牌仍属于格子效果。跨阶驿站同样保留印刷效果。本公开试玩版保留这一电子解释；它与纸面原文的差异在此明确列出。

导航与经过型装备

有【超算导航】时，只选择额外 0 或 1 格，公共移动、自己移动牌与受控移动都遵守此范围；受控移动时由被移动玩家决定是否加格。

“经过”按非最终格处理，只取对应资源，不额外摸基础牌；恰好落点按普通落点结算，不重复取得经过装备收益。每次经过触发单独开放响应；装备在窗口内被湮灭，本次触发取消。仅凭【空间探针】经过宇宙之眼不会获胜。

手牌、装备与立即牌

当前牌库为 正在读取…，其中常规 — 张，机遇 — 张。全部原始牌面与当前效果可在原作资料馆搜索查看。

  • 普通牌：自己的个人回合使用，按要求选目标或步数。
  • 装备牌：个人回合装入机动、交易或掠夺槽；每槽一张。换新时旧装备弃置，不回手，也可主动卸装。
  • 瞬发牌：在适用的响应窗口使用；【绝对湮灭】还可在个人回合主动弃置场上合法装备。查看牌上当前允许的目标。
  • 立即牌：取得后公开并处理，不作为普通手牌保留。同一玩家同时取得多张时，由本人决定先处理哪张。

【立即卸甲】先公开目标再允许响应。无合法装备时空结算；目标在响应中离场后，不追打替换装备。其他玩家的堡垒目标保护仍有效；这些是本版明确列出的电子裁定。

雷达与手牌上限

广域巡天雷达查看常规牌顶 3 张，深空扫描雷达查看机遇牌顶 2 张，选出本次应摸的数量；未选牌按持有者决定的顺序放回牌堆顶层。界面按“下一张最先摸到”提示排序。

个人回合结束时弃至最多 3 张；不超过 3 张时不能以结束回合为由额外自由弃牌。支付牌或地图格要求的弃牌代价，是另一类动作。

响应：保留反击也是选择

先看当前事件、合法目标与已经加入的牌，再决定是否响应；没有必要遇到窗口就用掉关键牌。双方依次得到响应机会，连续一圈无人继续加牌后，当前电子版从最后打出的牌开始逆序结算。

逆序响应是当前电子版裁定，与纸面表述存在差异本次纸面资料写“按出牌顺序依次结算”，没有写“后进先出”。本公开试玩版保留轮流响应与逆序反制链，不能据此宣称与纸面逐条完全一致。
反制例子你先打出掠夺，AI用绝对湮灭指向这张掠夺，你再用绝对湮灭指向AI的湮灭。若之后无人响应，先结算你的第二张湮灭，AI的湮灭失效，原掠夺再结算。交锋区会显示当前预计先结算的效果。
移动例子定向跃迁到白矮星：只结算能源与动力，不摸普通落点的基础牌；到印有“额外摸1张常规牌”的驿站：仍摸该额外牌；到未知星域：按该格专门效果摸机遇与常规各1张。跨阶后停止余步，结算所选驿站的印刷效果。
